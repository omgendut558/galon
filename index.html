Panduan Setup Supabase & Deploy Vercel

1. Cara Menyiapkan Database di Supabase

  1. Buka supabase.com dan buat akun / proyek baru gratis.
  2. Masuk ke menu SQL Editor di sidebar dashboard Supabase.
  3. Klik New Query, lalu salin dan jalankan seluruh isi file supabase_schema.sql yang sudah disediakan di folder proyek ini.
  4. Buka Project Settings -> API, lalu salin Project URL dan anon public API key.
  5. Masukkan kedua nilai tersebut ke dalam modal Pengaturan Database di aplikasi ini.

2. Cara Deploy ke Vercel (1-Click)

  1. Unggah folder proyek ini ke akun GitHub Anda.
  2. Buka vercel.com, lalu klik Add New... -> Project.
  3. Pilih repository GitHub Anda dan klik Deploy (Tanpa konfigurasi khusus, file vercel.json sudah otomatis aktif).

3. Fitur Filter Waktu Lengkap

Gunakan filter di dashboard untuk melihat rekapitulasi data berdasarkan Hari (misal performa penjualan tiap hari Sabtu/Minggu), Bulan, Tahun, atau Rentang Tanggal Kustom.
